## 验证证据

### 自动化

完整回归 **178 项通过（52.20 秒）**，覆盖此前聊天、任务取消/租约、SDK、MCP、注册邀请、ASR、文件版本和备份功能；Python 编译、22 个 JavaScript 语法、Markdown 链接和 diff 格式检查通过。新增 `tests/test_contacts.py` 13 项行为测试，覆盖：

- 初始化与目录边界、单向幂等添加、自身/Agent/停用目标及超限查询。
- 无联系人无法新建会话、先隐藏空私聊、首条消息后出现、接收者无需互加即可回复。
- 伪造归属参数、跨用户访问拒绝；授权服务器成员管理继续工作。
- 群邀请不导入联系人；双设备真实 WebSocket 收到联系人变化并拉取一致结果。
- 资料更新受众范围、CLI 建号、迁移只读预览/幂等、备份恢复与 Room 导出边界。
- 迁移保留含任务或交付物的空会话、群聊、Agent 私聊及已删除消息痕迹。

原回归 fixture 改为显式添加测试成员和主动打开既有私聊；产品初始化不再替测试或真实账号自动互连。故障和权限测试使用替身；本轮没有付费语言模型调用。

联系人初始化改动后额外重跑真实 SenseVoice 验收：WebM 普通话、Ogg 英文、M4A 粤语均完成识别，损坏/静音音频明确失败，实际 Agent 任务上下文包含本地转写。原样例近音词误差仍保留，不能据此宣称识别精确率已达标；结果存于本地 `output/asr-contacts-regression`。

### 真实 HTTP

运行 `scripts/verify_contacts.py`，使用独立临时数据库和随机测试账号，实际请求注册、查找、添加、创建会话、发送、回复、移除与历史读取；确认普通用户目录为空、管理员目录不可访问、空会话不出现在被动接收方列表。数据在本地忽略的 `output/contacts-acceptance` / `output/contacts-final-http`，不进入 Git。脚本默认结束后关闭测试服务，`--keep-running` 用于人工页面验收。

### 浏览器

在独立实例实测桌面及 390×844 手机尺寸：登录、空通讯录、精确查找/手动添加、列表搜索、资料卡发消息、发送文本、移除保留聊天、从已有聊天重新添加、选择联系人建群、群成员资料入口及返回栈。页面错误日志无错误。

验收发现并修正新资料卡替换与关闭旧弹窗时异步历史回退的竞争；资料卡和新建聊天先建立目标页面/层，再退掉旧层。修复后确认关闭资料卡、手机返回聊天/列表时留在应用。截图仅存本地输出目录。

手机尺寸验证使用浏览器视口模拟，未宣称已做 Android/iOS 实体设备、系统手势、弱网或离线推送验收。
