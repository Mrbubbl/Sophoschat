## 2. 本地语音转文字（P0）

### 使用入口

- 手机长按、桌面右键语音 → 转文字。不要求会话包含 Agent，不依赖 Claude API Key、AI 开关或聊天 Agent 在线。
- 文字显示在原语音下方；保留音频，不替换消息正文，不生成额外聊天气泡。支持复制、隐藏/显示；隐藏只影响当前客户端。
- 默认自动转写含 Agent 会话中新发送的语音；涉及语音的互动任务等待本地转写。引用历史语音并 @Agent 时，先识别其可访问的被引用语音。
- Agent 上下文、消息读取和后台整理共用转写缓存；按需工具可以识别尚未转写的可访问语音。
- 完成转写本身不触发新的 AI 发言。原互动任务仍遵循 V0.8 的触发、预算、有效期和取消规则。

### 状态与结果

- 未转写 → 排队 → 识别中 → 完成/失败。并发或重复请求复用工作；成功结果不重复识别。
- 状态持久化并推送，刷新后保留；重启重排中断工作。模型子进程异常/超时可回收，后续工作可恢复。
- 失败不写伪造文本；提示模型缺失、服务关闭、解码失败、时长超限、无清晰语音、超时或队列满，支持重试。
- 文字标识为语音转写。Agent 上下文明确其为机器识别、可能有误；失败时不得猜测内容。
- 转写写入原附件字段，更新来源消息版本和整理事件，使后台记忆能够重新读取新内容。

### 权限与运行

- 人类请求和查询检查会话成员及历史可见边界；Agent 每次调用还检查任务令牌。无权访问原音频也无权访问转写。
- 删除原消息清除转写和排队状态；迟到结果不得恢复被删内容。API 不返回内部路径和底层异常。
- 手动和自动请求共享有上限的串行队列。独立 CPU 子进程复用模型，空闲后释放，不阻塞聊天循环。
- 默认 SenseVoiceSmall int8 ONNX + sherpa-onnx；普通话/粤语/英/日/韩自动识别。FFmpeg 解码录音，按实际时长检查，默认最多 300 秒，长语音分段处理。
- ASR 不调用外部语音 API，首次安装需下载模型，之后推理离线。转写进入 Agent 回复/整理后，按现有语言模型供应商设置处理。
- 本轮不含实时通话字幕、说话人分离、逐字时间戳和录音前实时输入。

## 3. 验收

1. 无 Agent 会话长按语音可识别、复制、隐藏/恢复，其他成员能读取持久化结果。
2. 连点和多成员请求不重复识别/发消息；失败可重试，刷新和重启恢复状态。
3. 直接发给 Agent 的语音及被引用后 @Agent 的语音，其实际转写进入模型上下文。
4. 覆盖越权、历史不可见、删除中任务、旧代次结果、超时回收、队列限制和重启恢复。
5. 实际部署本地模型并用真实音频验证；故障和权限测试可使用替身，不能冒充真实识别验收。

部署见 [本地语音识别](ASR.md)；变更记录见 [更新日志](RELEASE_NOTES.md)。
