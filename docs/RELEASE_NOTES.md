## 升级提示

旧 Bridge 生产模式默认停用，不会静默回退到 mock、其他 API 或命令行适配器。升级前完整备份，浏览器需刷新以获取新静态资源。数据库迁移为追加式，回滚需考虑数据库兼容性。

所有 Agent 使用服务账号的完整工具权限，自主注册默认开放；这不等于为每个用户分配隔离的系统容器。完整执行模式与旧工具限制不同，详见 [部署说明](DEPLOYMENT.md)。

## 已知限制与后续范围

- 专用 GitHub 连接/分支/提交/PR 产品流程尚未实现；终端使用 Git/CLI 仍需认证。
- Word、PDF、Excel、PPT、图片及多文件 ZIP 尚未接入标准交付卡片与版本链。
- 外部 MCP 需要实际服务和认证；没有各服务专属 OAuth 登录页面。
- 语音可发送播放，生产 SDK 尚无语音转写工具；已有通话及旧 Notion 路径未纳入本轮 PRD 对齐验收。
- Room 导出尚未加入交付物打包；完整备份包含交付文件和工作区。
- 手机 Chrome/PWA 的国内后台推送未完成真机送达率验收；页面内 `new Notification()` 的移动兼容性问题仍待修正。未接入原生厂商推送。
- 公共搜索、外部网关和 MCP 服务可能限流或中断，成功状态以实际回执为准。
