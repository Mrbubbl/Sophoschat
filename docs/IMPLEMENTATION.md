# PRD V0.7 第 1–3 项实施记录

本地分支：`codex/server-sdk-artifacts`。源仓库提交：`e41aca11b11fea9c612418c7af5276e4dae93012`。本记录建立时尚未推送 GitHub；本次工作不包含公网部署。

## 1. 任务控制与权限

- 每次领取生成独立 lease generation，绑定任务、房间、凭证、控制器与租约；续租/完成/失败必须携带当前尝试证明。旧 token、撤销凭证、过期租约不能复活。
- 发起人或 Owner 才能取消/重试。取消、配置变更、源消息变更、成员范围变更使旧执行失效；控制器每秒检查租约，结束整个执行进程组。父进程死亡时 watchdog 清理遗留执行。
- 状态和错误按查看者所在 Room 过滤，包括 WebSocket 初始与后续推送。
- 自检采用真实 SDK + 作用域工具读取 + 持久文件 + 读回收据，心跳本身不能证明成功。自检消息、文件不进入记忆整理。

## 2. 服务器统一 SDK

- SDK 固定为 `claude-agent-sdk==0.2.176`。使用包内官方 Claude 运行时；本次实际版本为 2.1.316。
- 应用托管控制器并监控重启；每任务独立进程。`chat`、`delivery`、`memory` 分离工具权限，后台整理不能升级为交付或发消息。
- SDK 内置工具关闭，只注册作用域受限的平台 MCP 工具；不读取个人设置、插件、skills 或环境中的其他云凭证。执行目录与 SDK HOME 为平台私有目录。
- SDK session 绑定 Room、用途、交付 run、成员/原文范围、配置及指南版本，同一 session 串行。丢失 transcript 时有审计的重置标识，重新读取权限内上下文。
- Owner 设置页配置服务端加密 key、Claude 模型/网关、启停、后台整理开关、并发、互动预留、轮数、时间与费用限制。平台凭证不暴露给模型；API Key 不回传前端。
- 每次尝试记录模型、固定 SDK 版本、无密钥的配置快照、usage、已知费用或未知费用。重试不重复记账，未知费用预留继续占用额度，汇总覆盖整月而明细仅展示最近 200 次。
- SDK 返回的费用为估算；网关实际账单需由服务商核对。费用/轮数/时间限制不等于容器级 CPU、内存或出网隔离。当前模型无 Bash/任意文件工具，HTML 检查另起带浏览器沙箱和网络拦截的进程。

## 3. 对话文件交付

- 聊天请求可建立独立交付任务；真正保存后发布卡片，支持查看、下载、原文/渲染切换、复制与特定版本继续修改。
- UTF-8 Markdown 和自包含 HTML；一个任务一个文件，默认最多 2 MiB。不可变版本绑定来源任务/消息和父版本，SHA-256 校验；相同请求幂等，冲突内容或旧父版本拒绝覆盖。
- v2 不覆盖 v1；取消后已发布结果保留，重试先读回已有文件，避免重复卡片和文件。
- 文件读取、下载、预览均校验 Room 成员与历史可见范围，未经登录不可读取。HTML iframe 不赋予同源权限，CSP 限制网络、表单外发、嵌套页面、弹窗等能力。
- HTML 检查器支持实际 click/fill/expect_text，失败不发布；环境不可用则明确标记未验证。静态文件不被描述为已接入真实后端。
- 完整备份包含交付文件、加密配置所需密钥和 SDK 会话；自动化验证已覆盖文件版本与备份恢复。
