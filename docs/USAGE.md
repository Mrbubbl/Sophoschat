# 使用指南

## 注册与账号

部署者先用 CLI 创建唯一 Owner。登录页点击「没有账号？注册」，填写 2–32 位用户名、可选昵称、至少 8 位密码及确认密码，注册后自动登录。

新注册账号为普通成员，不自动获得 Owner 角色。Owner 可在「设置 → 工具与 MCP」关闭注册，或在「成员」中添加、停用账号。应用没有内置默认密码，GitHub 仓库也不包含本地测试账号。

## 与 Agent 对话

- Agent 私聊中发送消息直接触发；多人聊天中明确 `@agent`，或回复 Agent 的某条消息继续讨论。
- 引用文字和代码块内的 `@agent` 不触发；Agent 自己的消息不形成自我循环。
- 任务会显示排队、读取、执行代码、搜索、浏览、外部调用和保存等阶段。发起人或 Owner 可以取消和重试。
- 模型失败不影响普通聊天。取消停止当前执行及其进程组，已经发布的文件会保留。

## 文件与版本

示例：「按刚才讨论制作一个活动方案.md」。Agent 建立交付任务，文件实际保存后出现卡片。卡片可查看、下载；查看器支持原文/渲染切换及版本选择。

点击特定版本的「继续修改」，例如「时间改到周六，保留其他内容」。新版本绑定该旧版本，v1/v2 分开保存。若别人已发布更新版本，会报告父版本冲突，不静默覆盖。

当前交付卡片支持 UTF-8 `.md` 和自包含 `.html`，一个任务一个文件，默认最大 2 MiB。生成其他格式的能力与“能在聊天里稳定交付该格式”不同；二进制文件、多文件 ZIP 交付尚未接入这些卡片接口。

HTML 预览在限制网络和同源权限的沙箱中运行。检查器支持 click/fill/expect_text；未安装浏览器时标记未验证，检查失败则不发布。下载后的文件由本机浏览器按普通文件权限打开；页面中的演示表单不等于真实后端或已上线服务。

## 完整代码环境

示例：「在当前工作目录创建一个 Python 小项目，运行测试」「初始化 npm 项目，安装依赖并运行构建」。所有用途的 Agent 都可使用完整 Claude Code 工具，不逐次弹审批。

代码在服务器执行，使用服务账号权限。项目目录为 `data/agent_state/workspaces/room-<id>`，跨任务保留；SDK 配置更新不清空文件。应用不会自动为普通服务账号创建 root/sudo 权限。

费用、轮次、超时和并发仍受 Owner 设置控制。平台消息 API 按 Room 校验，而完整终端可访问服务账号能够访问的文件，因此不能将此模式理解成系统级隔离。

## 联网搜索与浏览

示例：「搜索 Python 官方文档，打开官网核对说明并附来源」。Agent 可以使用真实互联网搜索、网页正文读取，以及支持导航、点击、填写、JavaScript 和截图的浏览器。

默认搜索无需额外 Key；公共入口可能限流或触发挑战。Owner 可以在工具页切换服务，或配置 Brave、Tavily、SearXNG 的服务地址/凭证。搜索失败不代表聊天服务器离线，也不会伪造搜索结果。

## 外部 MCP

Owner 打开「设置 → 工具与 MCP」，在 JSON 编辑器中配置服务，保存后点击相应「测试」按钮。支持三种传输：

```json
{
  "calendar": {
    "type": "http",
    "url": "https://your-service.example/mcp",
    "headers": {"Authorization": "Bearer YOUR_SERVICE_TOKEN"}
  },
  "legacy-service": {
    "type": "sse",
    "url": "https://your-service.example/sse"
  },
  "local-service": {
    "type": "stdio",
    "command": "npx",
    "args": ["-y", "YOUR_ACTUAL_MCP_PACKAGE"],
    "env": {"API_KEY": "YOUR_SERVICE_KEY"}
  }
}
```

这些是格式示例，域名、包名和凭证必须替换为实际服务提供的信息。`platform` 是保留名称。stdio 命令需要能在服务进程 PATH 中找到；HTTP/SSE 服务要能从服务器访问。

headers、env、args 保存后以 `__UNCHANGED__` 显示；保留标记就会沿用旧值，替换为实际对象或数组可更新。删除服务项并保存即可撤销该连接，配置变化也会停止使用旧配置的任务。

连接测试实际执行 MCP 握手与工具列表查询，成功不等于所有业务操作都获得授权。日历、云盘等服务需要各自认证，MCP 工具也可能有配额或权限限制。本版本没有各服务专属 OAuth 登录页面，不会自动获取用户第三方账号。所有 Agent 可使用 Owner 已配置的 MCP 工具。

## Owner 用量与自检

「Agent 接入」配置模型、网关、API Key、启停、后台整理、并发、互动预留、轮次、超时和费用。单并发时互动预留设为 0；否则至少留一个名额给交付/整理。

自检会真实调用 SDK、读取上下文、保存文件并读回，执行中不显示“已通过”。心跳只是控制器在线信号。使用量中的 SDK 费用是估算；中断且未收到费用回执的尝试标记未知并继续保留预算，实际扣费以网关账单为准。
